
# Gestion des tâches Python

## Description
Application Python simple pour gérer les tâches quotidiennes.

## Fonctionnalités
- Ajouter une tâche
- Afficher les tâches
- Quitter le programme

## Étapes réalisées
- Création du programme Python
- Ajout du menu principal
- Gestion de la liste des tâches

## Exécution
Ouvrir main.py dans VS Code.
Cliquer sur Run Python File.
